## Key Flexbox Rule

> Flexbox is a one-dimensional layout system that arranges items along a main axis.

## Main Axis vs Cross Axis

- `flex-direction: row`
  - Main axis = horizontal
  - Cross axis = vertical

- `flex-direction: column`
  - Main axis = vertical
  - Cross axis = horizontal

## Responsive Navbar

The navbar switches to a vertical layout below 768px using a media query.
