# CSS Positioning Practice Project

This project demonstrates all major CSS positioning concepts with practical examples.

## Concepts Covered

- `position: static`
- `position: relative`
- `position: absolute`
- `position: fixed`
- `position: sticky`
- `z-index`

## Sections Included

1. Static Position
2. Relative Position
3. Absolute Badge
4. Fixed Chat Button
5. Sticky Header
6. z-index Overlap Demo

## Project Structure

```text
css-positioning-practice/
```

## How to Run

Open `index.html` in your browser and scroll to observe the fixed and sticky elements.
